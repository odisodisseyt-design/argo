# Preview captures

Этот каталог предназначен для реальных снимков приложения, которые публикуются
в README и в описании релиза. Их нужно снять с собранной APK на эмуляторе/устройстве
(средства Android Studio или `adb shell screencap` + `adb pull`).

Обязательные кадры:

| Файл | Сценарий |
|---|---|
| `entry.gif` | ритуал входа: обложка, breath glow, кнопка «Открыть книгу», page-turn |
| `ember_scene.png` | сцена с `mood=forge/night`, угли, тёплый свет, потоковый текст |
| `system_shop.png` | холодное «Окно системы» с вкладками из ui_manifest |
| `journal.png` | дневник с ожидающими фактами и восковой печатью |
| `level_up.png` | золотые чернила, +/- и счётчик «Осталось: N» |
| `waiting.png` | co-op ожидание: пульсирующая руна, «Ждём: …» |
| `death.png` | обесцвечивание мира, виньетка, «Здесь история заканчивается» |

Для GIF запишите короткий экранный ролик (≈3–5 с) и конвертируйте, например:

```bash
ffmpeg -i capture.mp4 -vf "fps=12,scale=540:-1" -loop 0 entry.gif
```

Изображения, сгенерированные на стороне, не являются снимками приложения и в этот
каталог не добавляются.
