# Theme packs

Initial selectable themes:
- SYSTEM (default): contemporary system-apocalypse / LitRPG HUD.
- FANTASY: parchment, brass and arcane motifs.
- SCI-FI: clean futuristic panels and cool light.
- DARK: restrained gothic palette.

A theme must preserve the same information hierarchy, accessibility and phase semantics. Theme selection is local presentation preference only.
